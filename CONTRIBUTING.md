# Contributing

Thanks for helping improve Top AI repos. Contributions are welcome when they make the list more accurate, useful, and easy to scan.

## What To Add

- Open-source AI, machine learning, data science, and developer-tool repositories.
- Frameworks, libraries, models, research codebases, benchmarks, and infrastructure that are useful to AI builders.
- Updates to repository metadata, links, descriptions, language, year, or star counts.
- Fixes for broken links, duplicated entries, outdated project names, or table formatting.

Please avoid closed-source products, promotional links, duplicate projects, inactive mirrors, and broad collections that are not directly focused on AI or machine learning.

## Entry Guidelines

- Search `README.md` first to avoid adding duplicates or near-duplicates.
- Use the canonical GitHub repository URL when possible.
- Keep descriptions factual, concise, and neutral.
- Preserve the existing table columns and Markdown table style.
- Use the main implementation language and project year when those values are clear.
- If you update star counts or rankings, keep the list sorted in decreasing order of stars.
- Verify that every link resolves before opening a pull request.

## Pull Request Checklist

Before submitting, please confirm that:

- The new or updated entry is open source and relevant to AI or machine learning.
- The project is not already listed under another name.
- Links, repository names, descriptions, language, year, and star counts are current.
- The Markdown table still renders correctly.
- The pull request title makes the change clear, such as "Add <project>", "Update <project>", or "Fix <project> link".

For larger reorganizations, open an issue first so the approach can be discussed before significant table changes are made.
